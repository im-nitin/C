This repository tracks my progress as I learn the fundamentals of C programming. It serves as a personal laboratory for testing out logic, mastering syntax, and building a strong foundation in low-level programming and algorithm design.

## 📂 DIRECTORY: SIMPLE ALGORITHMS

Here is an index of the basic logic scripts and mathematical algorithms currently in the repository:

| File Name | Description | Concepts Covered |
| :--- | :--- | :--- |
| `age_vote.c` | Checks if a user is eligible to vote based on their age input. | `if-else` conditions, relational operators |
| `average.c` | Calculates the average of multiple user-inputted numbers. | Arithmetic operators, floats |
| `division.c` | Performs division between inputs and handles remainders. | Arithmetic operators, type casting |
| `interest.c` | Calculates simple interest given principal, rate, and time. | Formula translation, formatted `printf` |
| `numcheck.c` | Evaluates a number (e.g., checking if it is even/odd or positive/negative). | Conditional branching, modulo operator |
| `scan_sub.c` | Takes two numbers via `scanf` and subtracts them. | Input/Output formatting |
| `sum.c` | Adds two user-provided numbers together. | Basic variables, memory addresses (`&`) |
