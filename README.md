## Overview

This repository is a personal collection of C programming practice focused on fundamentals, logic building, and chapter-wise exercises. It reflects a steady learning journey in understanding how C works in real-world problem-solving scenarios.

## Repository Flow

The project is organized in a progressive learning style, with practice files grouped by topic and chapter. Each section builds on the previous one and helps reinforce core programming concepts through small, focused programs.

## Getting Started

Make sure you have a C compiler installed, such as [GCC](https://gcc.gnu.org/) or [MinGW-w64](https://www.mingw-w64.org/).

```bash
git clone https://github.com/im-nitin/C.git
cd C
```

Compile any C source file in the project:

```bash
gcc your_program.c -o app
```

Run it on Linux or macOS:

```bash
./app
```

Run it on Windows PowerShell:

```powershell
.\app.exe
```

## Learning Focus

- Variables, data types, and operators
- Input and output using `scanf` and `printf`
- Conditional statements and logic flow
- Arithmetic and problem translation
- Structured chapter-wise practice and concept reinforcement

## Notes

This repository is intended for continuous learning and improvement. The goal is not just to write code, but to build a stronger understanding of programming logic and clean problem-solving habits.
